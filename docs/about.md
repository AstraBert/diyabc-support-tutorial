# About DIYABC support tutorial

This is a collection of best practices and suggestion that you should take into account when dealing with DIYABC.

This support tutorial does not cover all possible use cases and options, but is a good way to get started and reach an intermediate level of analysis with DIYABC.

This is supposed to be free learning material, and it is distributed under an MIT license.

This tutorial _might_ contain errors or things that can be improved, so you can refer to the [contribution page](./contributing.md) if you want to report/correct/enhance anything.
