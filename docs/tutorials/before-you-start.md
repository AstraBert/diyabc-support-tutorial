# Before you start

There are some important things that you should take into account before reading this tutorial section:

- Keep in mind that there are many use cases for DIYABC: we will focus only on **POPULATION DATA based on SNPs**
- We will be using some **R programming language**, so it will be useful for you to have a little bit of knowledge about it. If you do not know anything about R, here is a [free and complete 2 hours introduction to it](https://youtu.be/_V8eKsto3Ug?feature=shared)
- You can find all the code resources [here](https://github.com/AstraBert/diyabc-support-tutorial/tree/main/scripts) and all the data [here](https://github.com/AstraBert/diyabc-support-tutorial/tree/main/data)
- You should follow these steps:
    + First of all, understand how we [generate data](./generate-data.md)
    + Second, read about how we [approach DIYABC](./how-to-approach.md)
    + Third, follow up with [Tutorial 1](./tutorial-1.md) and [Tutorial 2](tutorial-2.md)
