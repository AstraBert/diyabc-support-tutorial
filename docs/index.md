# Welcome to DIYABC support tutorial!

This is a beginner-friendly guide to the power of DIYABC (Cornouet et al., 2014), a software designed to carry out ABC-supported coalescent simulations with variant and micro-satellite data from populations and individuals. 

You can find DIYABC documentation [here](https://diyabc.github.io/) and you can also read the supporting paper [here](https://doi.org/10.1093/bioinformatics/btt763).

That being said, let's dive deep into DIYABC!

> _IMPORTANT TIP: You should first go to the installation page, then follow the tutorials, then go the model selection section and, finally, read the goodness of fit and the parameter estimation portions_
